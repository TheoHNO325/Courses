# MITRA Parallel v2 藏文—中文数据评估记录

## 当前结论

MITRA Parallel v2 可以作为佛教/古典藏文领域的候选训练语料，但不应直接代表“通用藏文—现代中文”。其藏中训练数据由自动挖掘得到。藏文原始字段实际是 Wylie 拉丁转写而不是藏文 Unicode，训练前需要可追溯地转换，并保留原始字段。

仓库把 `score` 简述为平均对齐余弦，但本地全量数据中有 606 条大于 1.0，最大为 1.086。因此它只能作为内部排序信号，不能解释为概率、人工忠实度或严格的余弦值。后续必须先做人审，再决定是否以及如何使用该分数过滤。

MITRA-MT 随仓库提供的两套藏译中留出集已经固定到本地。它们只用于评测，不能进入训练或用于反复挑选超参数：

- TLB：2,000 对，佛教典籍，目标侧主要是繁体古汉语；适合评估佛经术语和经典语体。
- Lotsawa House：1,660 对，65 部作品、166 个连续文本块，现代宗教/祈愿文；适合评估现代宗教语体和段落上下文。

通用现代文本仍由 FLORES-200 单独评测。三者必须分别报告，不能只给一个混合平均分。

## 全量画像与主要风险

- `score`：最小 0.284，中位数 0.640，P95 0.911，最大 1.086；606 条大于 1.0。
- 长度：双语两侧最大字符数的中位数为 53，P95 为 185，最大为 2,148。
- 全部 836,559 条源文都没有藏文 Unicode 字符，源文是 Wylie；本地使用 `pyewts==1.0.0` 生成辅助藏文显示，不覆盖原文。
- 所有记录都是单一藏文源片段，但只有 471,652 条（56.4%）对应单一中文片段；364,907 条（43.6%）拼接了 2–28 个中文片段。
- 3,479 条中文含 ASCII 数字，可能包括页码、脚注号或正文数字，需要结合上下文判断。
- `gemini_score` 在全部记录中均为空，不能作为额外质量信号。

初步抽样已经看到一对多记录把相关译文与无关上下文共同拼接的情况。因此第一版基线建议优先从 471,652 条一对一记录中筛选；一对多记录暂不丢弃，但留到段落建模或更严格重对齐阶段。

## 保守结构过滤与文档划分

由于项目当前不依赖藏语人工评注，已建立一版只使用可重复结构规则的处理集。规则配置保存在 `configs/mitra_v2_filter.json`，处理脚本为 `src/prepare_mitra.py`：

- 必须是一对一藏中片段；
- Wylie 转换不能产生警告，且转换结果必须包含藏文字母；
- 中文目标必须包含汉字，排除 ASCII 数字；
- Wylie 源文长度 6–285，中文长度 3–86，目标/源字符长度比 0.03–3.81；
- 不使用 `score` 直接筛选，只在输出中保留原始 `score` 和分位层。

结果如下：

| 项目 | 数量 |
|---|---:|
| 原始记录 | 836,559 |
| 保留记录 | 451,135（53.9%） |
| 训练集 | 427,916 |
| 内部验证集 | 23,219 |
| 保留文档 | 676 |
| 训练文档 / 验证文档 | 638 / 38 |
| 文档交叉 | 0 |

验证集占保留记录的 5.15%，按 `filename` 完成文档级划分。FLORES、TLB 和 Lotsawa House 仍是最终外部评测集；内部验证集只用于训练过程中的早停和损失比较。

这一步只证明记录在格式、转写和结构上可用，**不证明藏中语义对齐正确**。训练前仍应在报告中明确这一限制。

第一版训练过滤建议在实际抽样后再定阈值，顺序为：

1. 先在一对一记录上检查 Wylie 转换、异常字符、极端长度和双语长度比。
2. 按 `score` 分层人工检查，而不是直接假设某个分数阈值等于“正确”。
3. 根据人工结果估计各分数层的可用率，再选择阈值或加权抽样策略。
4. 按 `filename` 划分训练/验证，禁止随机逐句切分。
5. 与 FLORES、TLB、Lotsawa House 做规范化重叠检查，保持评测隔离。

### TLB 佛教典籍集

- 两列、无表头，字段顺序为 `bo<TAB>zh`。
- 精确重复句对、重复藏文源句和重复中文目标句均为 0。
- 藏文字符长度中位数 116，95 分位数 402；中文分别为 23 和 84。
- 207 条中文含 ASCII 数字。抽样中可见疑似页码、脚注号和卷标题等编辑痕迹，后续人工检查要单独标注。
- 中文是繁体佛教经典语体；“中文流畅度”应按古汉语/佛经译文标准评估，不能按日常现代汉语评分。

### Lotsawa House 现代宗教文本集

- 8 列带表头：`work, translator, source_file, block_id, block_pos, source_line, bo, zh`。
- 65 部作品、166 个段落块；可同时做句级和段落级评测。
- 46 个完整句对重复，68 个藏文源句重复，48 个中文目标句重复。这是官方固定基准的一部分；若要报告与官方可比的分数，不应自行删重或重排。
- 藏文字符长度中位数 37，95 分位数 68；中文分别为 9 和 21。
- 1,630 条记录的 `translator` 为空，不能依赖该字段做译者风格分析。
- 来源站点许可为 CC BY-NC 4.0，只用于课程研究和评测更稳妥。
