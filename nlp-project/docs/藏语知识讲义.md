## 一、藏语是一门什么样的语言

藏语属于汉藏语系中的藏缅语族。它和汉语同属一个语系，但两者的差别非常大，远不是"同源所以相近"的关系。藏语主要通行于中国西藏、青海、四川西部、甘肃南部和云南西北部，以及尼泊尔、不丹、印度北部等地。

藏语不是一门单一的语言，而是一个内部差异很大的语言群。习惯上分成三大方言区：卫藏（以拉萨为中心，也叫中部方言）、安多（青海、甘肃一带）、康巴（四川西部、西藏东部）。三地的人用同一种文字书写，但口语往往互相听不懂。这个事实对后面的分词实验有直接影响——同一份书面文本，在不同方言区读出来是不同的音，甚至有无声调都不同。

传统上把藏语分成"书面语"和"口语"两套系统来讲，这个区分在本项目里很重要。书面语（尤其是古典藏文，即佛经、历史文献的写法）保留了大量古代语言的形态特征；现代口语（以拉萨话为代表）则已经演化成另一套样子。两者共用一套拼写，但语法结构差别不小。

## 二、藏文是怎么写的

### 2.1 字母与元音符号

藏文是拼音文字。它有一套辅音字母，大约三十个。这些辅音字母都是"自带元音 a"的——也就是说，单独写一个辅音字母，默认读作"该辅音 + a"。例如 ཀ 读 ka，ད 读 da，ག 读 ga。

如果要表示 a 以外的元音，就在辅音字母上加减号。藏文有四个元音符号：

- ི 表示 i。ཀ 加上它写作 ཀི，读 ki。
- ུ 表示 u。ཀུ 读 ku。
- ེ 表示 e。ཀེ 读 ke。
- ོ 表示 o。ཀོ 读 ko。

这些元音符号有个关键性质：它们不是独立的字符，而是"贴在"辅音上的。用 Unicode 的术语说，它们属于**组合记号**（combining mark）——一种不单独占位置、必须依附于前一个字符才有意义的符号。

这件事是理解整个项目的起点，后面还会反复回到它。

### 2.2 一个音节是怎么拼出来的

藏文的一个音节可以有相当复杂的结构。传统文法把它拆成七个位置，每个位置放不同类型的字母。这七个位置是：

**前缀**（藏文叫 སྔོན་འཇུག，sngon 'jug，字面意思是"放在前面的"）。能在最前面当前缀的只有六个字母：ག ད བ མ འ ས。它们在现代口语里基本不发音。

**基字**（མིང་གཞི，ming gzhi，"名字的根本"）。每个音节有且只有一个基字，它是这个音节的核心辅音。

**上置**（མགོ་ཅན，mgo can，"有头的"）。写在基字上方的小字母，只有三个：ར ལ ས。现代口语里也不发音。

**下置**（འདོགས་ཅན，'dogs can，"挂着的"）。写在基字下方的小字母，主要有 ྱ ྲ ླ ྭ 和 ྷ 几个。它们有的影响发音（让辅音腭化或唇化），有的不发音。

**元音**（དབྱངས，dbyangs）。就是上面说的四个元音符号。如果不写元音符号，就表示固有的 a。

**后置**（རྗེས་འཇུག，rjes 'jug，"跟在后面的"）。写在基字之后，有 ག ང ད ན བ མ འ ར ལ ས 十个。有的发音，有的不发音，但都会影响前面元音的音质。

**再后置**（ཡང་འཇུག，yang 'jug，"再跟上的"）。只能再追加 ས 或 ད 两个。

一个位置上能放什么字母，不是随便来的。藏文有严格的搭配规则，哪些字母能共现、哪些不能，都有定规。所以藏文里"合法的音节"是一个有限的集合，不是说随便拼都成立。

来看一个把七个位置都用上的例子：

```
བསྒྲུབས
```

这个音节的构成是：བ（前缀）+ ས（上置）+ ག（基字）+ ྲ（下置）+ ུ（元音 u）+ བ（后置）+ ས（再后置）。它的意思是"完成了"（动词的过去式）。请注意：**这是一个音节**，不是七个字，也不是一个词。它由七个码位组成。

**码位**（code point）是 Unicode 给每个字符分配的编号，写成 U+ 后面跟十六进制数字。比如 ཀ 是 U+0F40。码位是抽象的"身份证号"，和计算机实际怎么存储（比如 UTF-8 里用几个字节）是两回事。一个音节占七个码位，就意味着计算机里它是一串七个符号，而不是一个。

这一点直接决定了后面要做的事：既然是七个符号组成的一串，那么**在中间任何地方断开都是可能的**。而人类读它的时候，是把它当成一个整体来读的。

### 2.3 标点：tsheg 和 shad

藏文有两个重要的分隔符号。

**tsheg** 写作 ་，Unicode 编号 U+0F0B。它的作用是**标记一个音节的结束**。藏文在写的时候，每写完一个音节就打一个 tsheg，然后再写下一个。所以：

```
བོད་ཡིག
```

这里 tsheg 把文本分成了 བོད（bod，"藏"）和 ཡིག（yig，"文"）两个音节，合起来是"藏文"这个词。

需要强调的是：**tsheg 分隔的是音节，不是词**。这一点非常关键，因为很多人会误以为它像空格一样分词。它不分词。如果一个词有三个音节，中间就会有两个 tsheg。

**shad** 写作 །，编号 U+0F0D，作用类似句号或逗号，标记一个句子或短语的结束。还有一个双写的 ༎（U+0F0E），作用类似段落结束。

### 2.4 Unicode 类别，以及为什么它决定了整个实验

Unicode 给每一个码位都指定了一个**通用类别**（general category），用两个字母的缩写表示。这是标准预先定好的标签，说明这个字符是什么性质的东西，不需要人自己判断。常用的几个：

- **Lo**（Other_Letter，其他字母）：没有大小写之分的字母。汉字、藏文的辅音字母都属于这一类。
- **Mn**（NonSpacingMark，无空白组合记号）：不单独占宽度的组合记号。藏文的元音符号属于这一类。
- **Po**（Other_Punctuation，其他标点）：tsheg 和 shad 属于这一类。

在正则表达式里，`\p{L}` 的意思是"所有类别以 L 开头的字符"，也就是所有的字母，包括 Lo；`\p{M}` 的意思是"所有类别以 M 开头的字符"，也就是所有的记号，包括 Mn。

现在把前面的事实连起来：

藏文的辅音字母 ཀ 属于 Lo，**是**字母，匹配 `\p{L}`。
藏文的元音符号 ི 属于 Mn，**不是**字母，不匹配 `\p{L}`，只匹配 `\p{M}`。

这个差别看起来很技术化，但它正是本项目要研究的那个问题的根源。下一节说明为什么。

## 三、分词、子词切分，以及那个根本性的错配

### 3.1 两种"分词"要分清楚

中文语境里说"分词"，其实可能指两件完全不同的事。

第一件是**分词**（word segmentation），语言学意义上的任务：给定一串文本，判断哪些字符连起来构成一个"词"。中文没有空格，所以需要做这件事，jieba 就是干这个的。

第二件是**子词切分**（subword tokenization），工程意义上的操作：把文本切成模型能处理的、大小固定的单元（叫 token，词元）。BPE 就是干这个的。

这两件事的产物不一样：分词的产物是"词"，是有语言学定义的单位；子词切分的产物是"token"，是统计出来的单位，未必是词，也未必是语素，可能只是半个词或者两个词的碎片。它们服务的目的也不同：分词是为了给词性标注、句法分析、检索这类"需要词"的任务提供输入；子词切分是为了让语言模型有一个固定大小的词表，同时让序列尽量短。

现代语言模型（GPT、Qwen、Llama 等）用的都是子词切分，不用分词器。中国的语言模型不会先跑一遍 jieba 再训练，因为模型不需要"词"这个概念。

### 3.2 BPE 的两个阶段

BPE（Byte Pair Encoding）的工作分两步，这两步的区别在本项目里至关重要。

**第一步叫预分词**（pre-tokenization）。它的任务是先把文本切成若干"块"，规定哪些字符允许互相合并、哪些不允许。这一步通常用正则表达式做。GPT-2 用的那条正则里有一个分支是 `\p{L}+`，意思是"一串连续的字母，算作一个块"。

**第二步叫合并**（merge）。它在每个块**内部**，按语料中的出现频率，逐步把相邻的字符合并成更长的单元。合并的规则完全由统计决定。

关键约束在这里：**合并只在块内进行**。如果两个字符被预分词分到了不同的块里，那么无论你怎么训练、训练多少轮，它们都永远不可能被合并成一个单元。因为合并这一步根本看不到跨越块边界的组合。

### 3.3 于是问题出现了

把 3.2 的规则套到藏语上。

前面说过，GPT-2 的正则用 `\p{L}+` 定义"一个块"，也就是"一串字母"。而藏文的元音符号不是字母，是 Mn 类记号。

所以当我们处理 དི（di，由 ད 和 ི 两个码位组成）时：正则先匹配到 ད，因为它是字母；然后遇到 ི，它不是字母，`\p{L}+` 到这里就停了。结果这两个码位被分到了不同的块里。

再往后，合并这一步只能在各自的块内工作。ད 所在的块里只有它自己，ི 所在的块里也只有它自己。所以它们永远合成不了一个单元。

后果是：藏语的元音符号被系统性地"切"在了辅音之外，而且这与 BPE 学得好不好没有任何关系。即使你给它海量语料、训练很多轮，这个错配也不会自己消失，因为它在预分词阶段就已经确定了。

有一篇论文专门论证了这件事，标题叫《Vowel Signs Are Not Letters: A Pre-tokenization Ceiling on Multilingual Tokenizer Fertility》，意思是"元音符号不是字母：多语言分词器肥裕度的一个预分词天花板"。文中指出，凡是元音以符号形式附着的文字（藏文、以及印度系的许多文字），都会因为这条正则而遇到一个**肥裕度的下界**。所谓**肥裕度**（fertility），指的是"每个单位平均要被切成多少个 token"，这个数越大，说明文本被切得越碎、处理起来越费算力。

论文给了理论，但没有给出藏语的实际数字。这一点后面还会提到。

### 3.4 一个天然的对照组

藏语正字法里有一个特点，让这个问题变得可以被干净地测量。

藏语的固有元音 a 是不写符号的。也就是说，ད 这个字母本身就读 da，不需要任何附加符号。但如果要表示 di，就必须加上元音符号，写成 དི。

于是同一份语料里天然存在两组音节：

一组不含元音符号，比如 ད，整个音节就一个码位，而且是字母，`\p{L}+` 会把它完整吃下去，不受影响。
一组含元音符号，比如 དི，会被切成两块。

这两组音节的差别**仅仅在于有没有元音符号**，别的都一样。所以如果测量发现两组在"被切碎的比例"上存在差异，那么这个差异只能归因于那条正则，而不能用"藏语本来就难"来解释。

这在实验设计上叫做**对照**（control）。有了它，结论才有可能被归因到具体原因，而不只是"观察到相关"。

### 3.5 音节完整率与元音被切出率

基于上面的推理，可以定义两个测量指标。

**音节完整率**：一段文本里，有多少比例的音节在切分后没有被跨边界切开。具体地，对每个音节的字符区间，检查在这段区间内部有没有出现 token 的边界；如果内部没有边界，这个音节就是"完整的"。

**元音被切出率**：在音节内部，凡是出现"字母后面紧跟元音符号"这种相邻关系的地方，检查 token 的边界是否正好落在它们中间。落下了，就说明这个元音被从它的辅音上切了出去。这个指标最直接地反映了那条正则的作用。

这里要补充一个值得优先验证的推测。正则里除了 `\p{L}+`，还有一条分支是 `[^\s\p{L}\p{N}]+`，意思是"一串连续的非空白、非字母、非数字的字符"。tsheg（U+0F0B）的类别是 Po，既不是字母也不是数字，所以它也落在这条分支里。这意味着，如果 tsheg 前面紧挨着一个元音符号，而中间没有空格，那么这条分支会把**元音符号和 tsheg 一起吃进同一个块**。

举例来说，文本 `བོད་ཡིག` 里，第一个音节的结尾是 ད，然后是元音符号 ོ，然后是 tsheg ་。按这条分支的行为，ོ 和 ་ 很可能被归为一块。如果实测确实如此，那么 token 的边界不仅切碎了音节，还和音节边界完全错位了——tsheg 本该是音节的分界，结果却和上一个音节的元音粘在了一起。这比单纯"切碎"更严重，也更值得作为一个单独发现报告出来。

这个推测不需要特殊工具就能验证：把一段藏语喂进 tokenizer，把实际切分打印出来看一眼即可。

## 四、音节、词、句：三个层次，以及"词"的麻烦

### 4.1 三个层次

藏文的书写单位可以按三个层次理解：

**音节**。由 tsheg 分隔，是客观的、无歧义的。程序上按 U+0F0B 切分即可，不需要任何标注或人工判断。

**词**。由一个或多个音节构成。前面举过例子：བོད་ཡིག 是两个音节，但合起来是一个词，意思是"藏文"。另一个例子 མི་དམངས（mi dmangs，"人民"）也是两个音节一个词。

**句**。由 shad 分隔。

### 4.2 为什么"词"这一层有麻烦

麻烦出在：藏文**不用任何符号标记词边界**。tsheg 分的是音节，不是词。所以给定一串藏文，哪些音节应该合起来算一个词，是要靠词典和统计去判断的，而且不同的标注规范会给出不同的答案。

这不是一个小众问题。万维网联盟（W3C）的国际化工作组到近几年还在讨论"藏语的词边界该怎么界定""到底该采用哪种'词'的定义"。学术界也没有统一标准。

项目里为什么要在意这件事？因为实验需要选一个"分母"来算肥裕度。如果分母是"词"，那么换了分词标准，分母就变了，同一个 tokenizer 算出来的数字就会不同，别人无法复现你的结果。而如果分母是"音节"，因为音节由 tsheg 客观定义，任何人都能算出同样的数。

所以本项目把**音节作为主分母**，把"词"降为次分母，并且要求在使用词做分母时明确声明采用了哪套标准。这个选择本身也算是一点方法上的贡献，因为它解释了为什么前人报告的"每词 token 数"往往彼此不可比。

顺带说一句，中文也有类似处境：中文有 PKU、MSR、CTB、CityU 等好几套分词标准，同一个句子各家切法不一致。所以"词这一层是人为的、有争议的"并不是藏语独有的问题，只是藏语因为缺少广泛使用的标准，问题更突出。

## 五、藏语的语法骨架

### 5.1 语序

藏语的基本语序是主宾动（SOV），也就是动词放在句子最后。"我喝茶"这个意思，藏语按"我 茶 喝"的顺序排列。这一点和日语类似，和汉语、英语的主谓宾（SVO）相反。

藏语用的是**后置词**而不是前置词。汉语说"在屋里"，英语说 in the house，藏语相当于说"屋里-在"，方位词跟在名词后面。

### 5.2 格助词：藏语靠什么表明"谁对谁做了什么"

汉语和英语主要靠**语序**来确定句子成分的角色。"我吃饭"里，"我"在动词前，所以是施事；"饭"在动词后，所以是受事。位置变了，意思就变了。

藏语主要靠**格助词**（case particle）。格助词是跟在名词后面的一个小词（在藏语里它通常自己就是一个音节），用来说明这个名词在句子里担任什么角色。日语里的「は」「が」「を」「に」就是同类的成分。

看一个例子：

```
བདག་གིས་ཆོས་ཉན།
bdag gis chos nyan
我(作格) 法 听
→ 我听法
```

这里 བདག 是"我"，后面跟了 གིས。这个 གིས 就是**作格助词**（ergative particle），它标记"我"是及物动词的施事。然后把 གིས 换成属格助词 གི，意思就变了：

```
བདག་གི་ཆོས།
bdag gi chos
我(属格) 法
→ 我的法
```

同一个名词 བདག，后面跟不同的助词，在句子里扮演的角色完全不同。这就是格助词的作用。

常用的格助词有这么几类：

**作格／工具格**，主要形式有 གིས、ཀྱིས、གྱིས 和 ས，表示及物动词的施事，也可以表示工具（"用某物"）。

**属格**，主要形式有 གི、ཀྱི、གྱི 和 འི，表示领属关系，相当于汉语的"的"、英语的 of 或 's。

**向格／处格**，形式是 ལ，表示方向、对象或位置，大致相当于汉语的"给""在"。

**从格**，形式有 ལས 和 ནས，表示来源，也用来构成比较句（说"A 比 B 大"，藏语的构造是"A B-从格 大"）。

**随同格**，形式是 དང，表示"和、与"。

### 5.3 格助词的一个麻烦性质：音系条件变体

上面列出的形式里，同一个格有好几种写法。这不是随意选择，而是取决于**前一个音节末尾的音**。

这个现象叫**音系条件变体**（allomorph），意思是：同一个语法成分，因为所处的读音环境不同，而呈现出几种不同的形式。英语的复数就是这样：cats 加 -s，boxes 加 -es，加哪个取决于词尾是清音还是咝音。

藏语属格有 ཀྱི、གྱི、གི、འི 四种形式，选哪一个取决于前一个音节以什么音收尾——收尾音不同，接的助词形式就不同。（各形式对应的具体收尾音，以藏文文法教科书为准；本文只说明这个机制存在。）

对语言模型来说，这件事的坏处是这样的：这四个形式，在意义上完全一样，都是"属格"。但因为写法不同，分词器很可能把它们切成四个互不相关的单元。模型于是看到四个长得毫无关系的符号，只能分别记住"这个形式出现在这种位置""那个形式出现在那种位置"，而学不到"这四个其实是同一个东西"。

数据量充足的时候，靠死记也能学会。但藏语恰恰是低资源语言，数据本来就不够，如果连这种最基本的语法规律都要靠死记，模型就很难真正掌握藏语的句法。

这一点和英语形成对比。英语的 cats 和 boxes，词尾差异在字母上，BPE 切出来是 cat + s 和 box + es，至少词干部分是共享的，模型能看出规律。藏语的 གི 和 ཀྱི 之间没有任何共享部分，是两个完全不同的符号串。

### 5.4 格助词的两种书写形式

还有一件事需要留意：格助词有两种写法。

一种是自己独立成一个音节。比如属格的 གི、ཀྱི、གྱི，作格的 གིས、ཀྱིས、གྱིས，它们都占一个 tsheg bar，前面有 tsheg 和名词隔开。

另一种是附着在前一个音节内部。最典型的是作格的 ས，它作为一个后置字母写在前面那个音节的末尾，和前面的音节共享同一个 tsheg bar。比如"我"的作格形式 ངས（ngas），就是 ང 加上 ས 写在一个音节里。

这两种形式对程序来说难度不同。独立成音节的那种，只要按 tsheg 切分就能直接找到，纯字符串匹配即可。附着在音节内部的那种，藏在音节里，需要做形态分析才能识别。

所以本项目第一版只处理独立成音节的那一类，把附着形式明确列为未覆盖范围。这是为了控制工作量，也是一种诚实的边界声明。

### 5.5 作格与绝对格

藏语的格系统里有一个和汉语、英语都不一样的安排，叫**作格-绝对格配列**（ergative-absolutive alignment）。

先说汉语和英语的做法。在这两种语言里，及物句的主语和不及物句的主语用同样的形式，宾语用另一种。比如"我吃饭"的"我"和"我睡了"的"我"形式一样，都是主格；"饭"是宾格。这叫作格-宾格配列。

藏语不同。在藏语里，及物句的施事（"我吃饭"的"我"）要带一个专门的标记，就是作格助词；而不及物句的主语（"我睡了"的"我"）和及物句的宾语（"饭"）用同样的、不带标记的形式。这个不带标记的形式叫**绝对格**。也就是说，藏语把"不及物主语"和"宾语"归为一类处理。

这个差异对翻译有实际影响。汉语和英语都不标记格，所以从藏语翻译过去的时候，格的信息必然丢失；反过来，从汉语翻译成藏语的时候，模型必须自己推断这里该不该加作格助词——而这需要理解句子的施受关系，不是单纯的词汇对应问题。

这类错误用 BLEU 之类的自动指标是看不出来的，因为加不加一个助词对字面重合度的影响很小，但语法上却是错的。

### 5.6 否定、疑问与从句

藏语的否定用 མ 或 མི（ma、mi）表示，位置和现代汉语的"不"不完全对应。

疑问句不改语序，而是在句末加助词，比如 འ 或 ས，或者用 མ。这一点和汉语不同——汉语的疑问要么加"吗"要么改语序（"你吃饭"变成"你吃饭吗"或"你吃不吃"），藏语是纯加助词。

条件从句和时间从句也在句末用助词标记，条件用 ན（na），时间用 ཚེ（tshe）。英语用 if、when 这类连词放在从句**前面**，藏语放在**后面**，这个方向差异在翻译时需要重排。

关系从句放在被修饰的名词**前面**，用名词化标记 པ 或 བ（pa、ba）构成。这一点英语是后置的（the man who came），藏语和汉语都是前置的，所以藏汉之间的关系从句反而比较好处理。

比较句用从格，前面提过。"A 比 B 大"在藏语里的构造是"A B-从格 大"。

藏语没有冠词，也没有英语里 it、there 这种虚主语。

### 5.7 敬语

藏语有一套**敬语**系统，藏文叫 ཞེ་ས（zhe sa）。它的做法不是像汉语那样加"您"、加"请"，而是对尊长说话时把某些词**整个换掉**。

举几个例子。"头"平常说 མགོ（mgo），敬语说 དབུ（dbu）。"吃"平常说 ཟ（za），敬语用 ཞེས 或 གསོལ（zhes、gsol）。人称代词也分：第二人称"你"平常说 ཁྱོད（khyod），敬语说 ཁྱེད་རང（khyed rang），大致相当于"你"和"您"的区别，但用法更严格。

对翻译来说麻烦在于：**源文本里根本没有"该用敬语"这个信息**。如果从汉语或英语翻译成藏语，原文不会告诉你这里的对象是尊长还是平辈，模型只能猜。而且现有的自动评测指标完全不测语域，所以就算猜错了，分数也看不出来。

本项目没有母语者，无法对这一项做评测，因此把它明确列为局限。

### 5.8 示证性

**示证性**（evidentiality）指的是：语法上强制要求说话人表明"这个信息你是怎么得到的"——是亲眼所见、是听说的、还是推断出来的。

藏语口语里有这套系统。它的表现方式是选择不同的助动词。比如 ཡིན（yin）和 རེད（red）这一对：前者用于说话人自己直接知道的情况，后者用于客观陈述或非亲知的情况。存在动词也有类似的对立：ཡོད（yod）和 འདུག（'dug）。

这与汉语、英语都不同。汉语可以用"据说""看起来"这类词来表达信息来源，但那是可选的词汇手段，不是语法强制的。藏语是强制的：你必须在助动词上做出选择。

对翻译的影响和敬语类似：源文本不会告诉你说话人是否亲见，模型只能猜。而且这也属于评测算不出来的东西。同样列为本项目的局限。

## 六、动词系统

### 6.1 没有人称变位

先澄清一个常见的误解。藏语动词**不随主语的人称和数变化**。汉语说"我吃""他吃"，英语说 I eat、he eats（第三人称单数加 -s），藏语不管主语是谁，动词形式都一样。所以严格意义上的"变位"（conjugation，指动词因人称、数、时态而变形）在藏语里是不存在的。

### 6.2 书面语：四词干

但书面藏语的动词确实有形态变化，而且变化方式相当复杂。传统文法把动词分成**四个词干**：

**现在词干**（ད་ལྟ་བ，da lta ba，"现在的"）
**过去词干**（འདས་པ，'das pa，"过去的"）
**未来词干**（མ་འོངས་པ，ma 'ongs pa，"未来的"）
**命令词干**（སྐུལ་ཚིག，skul tshig，"驱使的话"）

同一个动词在这四个词干上的形式可能差别很大。变化的手段包括元音交替（同一个辅音框架里换元音）、辅音交替、加或换前缀、加或换后缀，以及**异根**（suppletion，指同一个词的不同形式来自完全不同的词根，比如英语的 go 和 went，went 原本是另一个动词）。

看一个例子，"做"这个动词：

```
现在 བྱེད   byed
过去 བྱས   byas
未来 བྱ    bya
命令 བྱོས   byos
```

可以看到辅音和元音都在变。这类变化在语言学上属于**屈折**（inflection），也就是通过改变词本身的形式来表达语法意义。所以书面藏语保留了相当古老的一套屈折形态。

### 6.3 口语：助动词系统

现代口语里，这套词干系统已经基本不用了。时态、体、示证、人称这些信息，改由**助动词和虚词**来表达。

助动词是跟在主要动词后面的小词，它们承担语法功能。5.8 节讲的示证对立就是在助动词上体现的。

还有一个值得注意的现象：拉萨话**新产生**了一套人称标记系统，第一人称和第二、三人称在对某些助动词的选择上不同。这是古代藏语所没有的，属于后起的变化。

口语里还常用方向性的动词来区分动作的趋向，比如 ཕྱིན（phyin，表示离开说话人）和 ཡོང（yong，表示朝向说话人）。这种信息在汉语和英语里通常不通过动词本身表达。

### 6.4 时与体

这里要区分两个容易混淆的概念。

**时**（tense）说的是"这件事发生在什么时候"——过去、现在、将来。

**体**（aspect）说的是"这件事处于什么状态"——是完成了、正在进行、还是曾经经历过。

藏语更偏向用体而不是时来组织句子。汉语在这点上和藏语比较接近：汉语的"了""着""过"都是体标记，而且汉语不强制标时。"我吃了饭"的"了"表示完成，不一定表示过去——"明天吃了饭再说"也完全成立。英语则强制标时，任何句子都必须落在某个时态上。

这个差异带来一个可以预测的结果：从藏语翻译成汉语，比从藏语翻译成英语要容易一些，因为汉语不需要模型去补一个源文里没有的时态信息。反过来，从藏语翻成英语时，模型必须推断出时态，而源文可能根本没提供这个信息。

这个预测是可以验证的：拿同一个模型、同一份藏语语料，只把目标语言从汉语换成英语，比较两边的错误类型分布。如果预测成立，两边的错误模式应该明显不同。这是本项目可以顺带做的一个对比实验，成本几乎为零。

### 6.5 语态：核心是使动，不是被动

汉语和英语的语态主要讲主动和被动：英语的被动是 be + 过去分词（The window was broken），汉语是"被"字句（窗户被打破了）。

藏语的核心对立不在这里。藏语最突出的语态对立是**使动**（causative）和**非使动**（anticausative）：前者表示"使某物发生变化"，后者表示"某物自身发生变化"。

这个对立在古代藏语里靠前缀来标记。看一对例子：

```
འཇིག   'jig    坏掉、被毁（非使动）
བཤིག   bshig   使坏、摧毁（使动）
```

差别就在那个 b- 前缀上。这正好和 2.2 节讲的前缀呼应：那些今天不发音的前缀，在古代是有语法功能的，其中之一就是标记使动。

现代藏语表达使动，要么换用另一个动词，要么用迂回的说法，比如用 བྱེད（byed，"做、使"）加上名词。

至于被动，藏语**没有英语那种形态上的被动**。被动的功能由几种方式分担：用不及物结构、用特定的句式，以及——这一点很有意思——由作格系统本身承担。前面说过，作格语言里绝对格同时负责"不及物主语"和"及物宾语"两种功能，这就在很大程度上消解了"需要把宾语提升为主语"的动机。作格语言普遍不太需要被动式，原因就在这里。

对翻译来说，这意味着从汉语的"被"字句翻译成藏语时，找不到一一对应的构造；从藏语翻译成汉语时，作格结构需要被"拉平"成汉语的语序。这是结构性差异，不是词对词的差异，也是机器翻译出错的一个常见来源。

## 七、发音，以及为什么拼写帮不上忙

### 7.1 拼写和读音严重脱节

藏文的正字法是在公元七世纪左右制定的，之后基本没改过。但口语一直在变。结果是今天的读音和拼写之间隔了上千年。

具体地说：2.2 节讲的那些前缀字母（ག ད བ མ འ ས），在现代藏语里**基本不发音**。上置字母（ར ལ ས）也不发音。一部分下置字母不发音，另一部分会影响发音（让辅音腭化或唇化）。后置和再后置字母有的发音、有的不发音，但不发音的那些往往会影响前面元音的音质，甚至影响声调。

回到那个例子 བསྒྲུབས。它有七个码位，但读出来只是大概两三个音。也就是说，拼写上的一大半信息在现代口语里已经消失了。

这造成一个后果：**你无法从拼写可靠地推出读音，也无法从读音可靠地推出拼写**。这在语言学上叫"形容对应不透明"。

### 7.2 声调

拉萨话和康巴话是**有声调**的，安多话**没有声调**。声调在藏文拼写里**完全不标**。

藏语声调是怎么来的？这牵涉一个语言学概念叫**声调发生**（tonogenesis）：一种语言本来没有声调，后来因为某些语音区别消失，这些区别就转移到音高上，于是产生了声调。藏语的情况是：古代的前缀脱落、清浊辅音的对立消失，原本靠辅音区分的词，后来只能靠音高来区分，声调就这样出现了。

这件事和本项目有什么关系？关系在于**同一份书面文本对应着不同的音系系统**。卫藏人读它带声调，安多人读它不带声调，而拼写完全一样。所以一个只处理文本的模型，从根本上无法获得发音信息，也无法从文本预测声调。这也意味着语音合成或语音识别不能从纯文本自举，必须依赖额外的语音数据。

有一项计算研究专门考察了这个问题，题目是《The Tonogenesis Continuum in Tibetan: A Computational Investigation》，研究了在不同声调发生阶段的方言中，音高的变化如何影响语音识别。这项研究从计算的角度量化了"同一书写形式、不同音系系统"的实际后果。

### 7.3 三大方言

卫藏方言以拉萨为中心，通行于西藏中部和西部。它丢失了古代的复辅音，有声调。

康巴方言通行于四川西部和西藏东部。它部分保留了复辅音，也有声调。

安多方言通行于青海和甘肃一带。它保留了大量复辅音，没有声调。

三地使用同一种文字，但口语差异大到互相难以通话。安多话和卫藏话恰好处在"声调发生"这条连续谱的两端，这在语言学上是个很有名的例子。

对本项目的影响是：如果做纯文本的工作，方言可以暂时不管；但如果要引方言数据，需要注意同一段文字在三地的读法完全不同。

## 八、词汇与构词

### 8.1 复合构词

藏语很能造复合词。一个词往往由两到四个音节构成，通过把几个语素拼在一起来表达新意思。前面举的 བོད་ཡིག（藏文，藏 + 文）和 མི་དམངས（人民，人 + 众）都是复合词。

这带来一个下游问题：词形数量很大，词表容易膨胀。而词表越大，每个词分到的训练信号就越少。这和前面讲的分词问题叠加在一起，会让词汇表示变得更加困难。

### 8.2 那些不发音的前缀

再回到 2.2 节的前缀。这些字母在现代藏语里不发音，但它们在拼写上占着位置。对 BPE 来说，这是个麻烦：BPE 是按频率统计来切分的，它不知道哪些字母表义、哪些只是历史遗留。所以它会把不表义的前缀字母也当成子词的一部分来统计，结果切出来的单元和真正的语素单位对不上。

这种错位是系统性的，不是偶发的。

### 8.3 梵文借词

藏传佛教的经典大量译自梵文。翻译的时候，很多梵文词没有被意译，而是**音译**——用藏文字母把梵文的读音拼出来。比如 ཤྲཱི（shrī）就是梵文"吉祥"的音译。

在佛典语料里，这类音译词密度很高，而且往往有不止一种拼写方式。这造成两个问题：一是未登录词（词典里没有的词）特别多；二是同一个梵文词可能有几种藏文写法，影响术语的一致性。

这里有个现实的关联：佛典是目前免费藏语文本的最大来源。也就是说，语料最多的那个领域，恰好也是这类问题最密集的领域。

### 8.4 数字与历法

藏文有自己的一套数字符号，从 ༠ 到 ༩（Unicode 编号 U+0F20 到 U+0F29），对应 0 到 9。现代文本里也常用阿拉伯数字，两种混用的情况很常见。

日期方面，藏历使用一种叫 རབ་བྱུང（rab byung）的纪年法，是一个六十年循环的系统。要正确处理藏文文本里的日期，需要专门处理这套历法，这本身是一个独立的小工程。

### 8.5 文本里的其他噪声

实际语料里还有几类需要注意的问题。

tsheg 的用法不总是规范。在用户产生的文本（比如社交媒体）里，tsheg 经常被省略、重复或者放错位置。这会直接影响按 tsheg 切音节的可靠性。规范语料（佛典、司法文书）上问题不大，但网络语料需要先清洗。

异体字问题。同一个音节可能有几种拼写方式，尤其在叠字的写法上。

规范化不唯一。前面提到藏文的组合记号在 Unicode 里有类别定义上的缺陷，导致某些字符序列没有唯一的规范排序形式。这意味着两个"看起来完全一样"的字符串，在计算机里的字节表示可能不同。如果不去重前先做规范化，去重和检索都会失效。这是个很实际的坑。

威利转写混用。学术界习惯用拉丁字母转写藏文（就是本文中出现的那些 byed、byas 之类），这套系统叫威利转写（Wylie）。不同语料可能混有藏文原文和拉丁转写两种形式，处理时需要分别对待。

字体依赖。藏文的叠字结构复杂，需要专门的字体才能正确渲染。如果环境里没有相应字体，显示出来就是方框（俗称"豆腐块"）。有些处理流水线因此不得不避开纯文本路径，转而使用图像方式。

## 九、把这些知识连起来

上面讲的这些，和本项目的关系可以这样理解。

藏语的文字有两个层次是客观、明确、不需要人工判断的：字符的 Unicode 码位，和由 tsheg 标记的音节边界。这两个层次给了我们一个可靠的测量基准。

而"词"这个层次是人为的、有争议的、依赖标准的，所以不适合做测量的分母。

问题出在中间：一个音节由多个码位组成，而主流的子词切分方法在预分词阶段用"字母"来定义可合并的单元，藏语的元音符号又不是字母。于是元音被系统性地切出单元之外，而合并这一步无法跨越预分词设定的边界，所以这个错配在统计学习开始之前就已经固定下来了。

这件事的后果分三层。第一层是效率，文本被切得更碎，同样算力能处理的藏语内容更少。第二层是正确性，音节被切开，模型看到的是不完整的书写单位。第三层是可学性，格助词的几个音系变体本来表达同一个语法范畴，被切碎之后在模型眼里成了互不相关的符号，而格助词恰恰是藏语句法的骨架，在低资源条件下靠死记是学不会的。

反过来看，藏语正字法里"固有元音 a 不写符号"这个特点，恰好提供了一个天然的对照组：含元音符号的音节和不含的音节，在同一份语料里同时存在，唯一差别就是那个符号。于是任何测量到的差异都可以被归因到预分词规则上，而不是"藏语本来就难"这种无法验证的说法。

至于敬语、示证性、方言差异、时态推断、作格转换这些难点，它们要么需要源文根本不提供的信息，要么需要母语者判断，要么需要额外的语音模态。在现阶段把它们写清楚、列为局限，比硬做要有价值。
